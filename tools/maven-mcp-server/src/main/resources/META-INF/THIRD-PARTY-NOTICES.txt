Apache Maven MCP Server: third-party software in the runnable jar
===================================================================

The runnable jar (maven-mcp-server-<version>.jar) contains these libraries unchanged:

  io.modelcontextprotocol.sdk:mcp-core:2.1.0             MIT        https://github.com/modelcontextprotocol/java-sdk
  io.modelcontextprotocol.sdk:mcp-json-jackson2:2.1.0    MIT        https://github.com/modelcontextprotocol/java-sdk
  org.slf4j:slf4j-api:2.0.16                             MIT        https://github.com/qos-ch/slf4j
  org.slf4j:slf4j-jdk14:2.0.16                           MIT        https://github.com/qos-ch/slf4j
  com.fasterxml.jackson.core:jackson-core:2.21.1         Apache-2.0 https://github.com/FasterXML/jackson-core
  com.fasterxml.jackson.core:jackson-databind:2.21.1     Apache-2.0 https://github.com/FasterXML/jackson-databind
  com.fasterxml.jackson.core:jackson-annotations:2.21    Apache-2.0 https://github.com/FasterXML/jackson-annotations
  com.fasterxml.jackson.dataformat:jackson-dataformat-yaml:2.18.4 Apache-2.0 https://github.com/FasterXML/jackson-dataformats-text
  io.projectreactor:reactor-core:3.7.0                   Apache-2.0 https://github.com/reactor/reactor-core
  org.reactivestreams:reactive-streams:1.0.4             MIT-0      https://github.com/reactive-streams/reactive-streams-jvm
  com.networknt:json-schema-validator:2.0.4              Apache-2.0 https://github.com/networknt/json-schema-validator
  com.ethlo.time:itu:1.14.0                              Apache-2.0 https://github.com/ethlo/itu
  org.yaml:snakeyaml:2.3                                 Apache-2.0 https://bitbucket.org/snakeyaml/snakeyaml

The Apache-2.0 license text is in META-INF/LICENSE and the merged notices of the Apache-2.0 libraries are in
META-INF/NOTICE. The MIT license texts follow.
