# Third-party JSON streaming runtime

The separately packaged M3 original analyzer report adapter includes:

- Maven coordinates: com.fasterxml.jackson.core:jackson-core:2.22.4
- Original upstream: https://github.com/FasterXML/jackson-core
- Original license: Apache License, Version 2.0
- Purpose: bounded streaming intake of SARIF 2.1.0 JSON generated by
  original CodeQL and other analyzer tools
- Distribution: relocated under a private adapter package by the
  Maven Shade Plugin to avoid Maven/Gradle class-realm conflicts

The original Jackson implementation is not authored by this project.
Retain upstream Apache license and NOTICE metadata in distributions.
The original standalone XML converter continues to use JDK StAX;
no Jackson class is introduced into Maven Core or the Gradle plugin.
